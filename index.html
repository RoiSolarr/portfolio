WEB APPLICATION

Shortlist: AI Job Application Assistant

An AI job application assistant that scores how well a job post fits your resume before you spend an hour applying. Paste a link or the description, and an n8n workflow with Google Gemini returns a fit score out of 100, matched skills, gaps to address and a tailored cover letter, then tracks every application on a drag and drop board from Saved to Offer.

TOOLS & TECH
Next.js TypeScript Tailwind CSS Supabase n8n Gemini API Render Vercel

Moved the slow work (reading the job post, PDF resume extraction and the Gemini call) into an n8n workflow on Render, so the automation can change without redeploying the site. The browser never sends a user ID: the server verifies the session and passes it to n8n behind a shared secret, and row level security plus composite foreign keys keep every resume and application scoped to its owner, even when n8n writes with the service role.

NexaBase: AI Knowledge Base & Document Search

A secure RAG-powered knowledge base platform that makes document search and team knowledge-sharing easier to manage, with a Supabase pgvector store, Google Gemini embeddings, and chat answers that cite the exact passage they came from.

TOOLS & TECH
Next.js TypeScript Supabase Prisma Gemini API Vercel

Access control uses Supabase row-level security, scoping every query to the signed-in user at the database layer instead of trusting the client. Documents are chunked into ~1000-character passages with overlap, so pgvector search returns passages precise enough to cite, not just summarize, and each response streams as it generates.

MOBILE APPLICATION

Sneakervault: Sneaker Inventory & Portfolio Tracker

A secure sneaker inventory and analytics platform that makes collection tracking and portfolio valuation easier to manage with a Supabase cloud database, Brevo notification services, and real-time wear-log insights.

TOOLS & TECH
Flutter Dart Supabase Brevo Netlify

Built the authentication layer using Supabase's row-level security instead of custom middleware, so every query is scoped to the owning user at the database layer rather than trusted to the client — reducing the attack surface for a personal-inventory app handling users' collection values. Designed the 30-day wear-log alert using a scheduled query against `last_worn_at` rather than a live cron job, keeping the feature serverless-compatible on Supabase's free tier.
